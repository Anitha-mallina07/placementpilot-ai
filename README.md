# PlacementPilot AI

PlacementPilot AI is an AI-powered career mentor designed to help students prepare for placements through personalized roadmaps, mock interviews, skill-gap analysis, and learning recommendations.

## Features

- AI Placement Mentor
- Skill Gap Analysis
- Personalized Learning Roadmaps
- Mock Interview Preparation
- Career Guidance
- Progress Tracking

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- GitHub Copilot
