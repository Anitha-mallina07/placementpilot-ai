# 🚀 PlacementPilot AI

An AI-powered placement preparation platform designed to help students assess their career readiness, identify skill gaps, explore career opportunities, and receive personalized guidance through Artificial Intelligence.

🌐 **Live Demo:**  
https://placementpilot-ai-1.onrender.com

---

## 📖 Overview

PlacementPilot AI assists students in preparing for placements by analyzing their skills, target career roles, and academic profile. The platform generates AI-powered career insights, readiness scores, and recommendations to help students plan their learning journey effectively.

## 📸 Application Workflow

1. User registers or logs in.
2. User accesses the dashboard.
3. Student enters academic and skill details.
4. AI analyzes the profile.
5. Readiness score is generated.
6. Career recommendations are provided.
7. Student receives personalized guidance.

## 📂 Installation

### Clone Repository

```bash
git clone https://github.com/AnithaMallina/placementpilot-ai.git
```

### Frontend Setup

```bash
cd client
npm install
npm run dev
```

### Backend Setup

```bash
cd server
npm install
npm start
```

---

## 🔑 Environment Variables

Backend `.env`

```env
MONGO_URI=your_mongodb_connection_string
PORT=5000
GROQ_API_KEY=your_groq_api_key
JWT_SECRET=your_secret_key
```
