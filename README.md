# PlacementPilot AI

## Overview

PlacementPilot AI is an intelligent career mentor designed to bridge the gap between learning and employability. The platform analyzes a student's skills, identifies improvement areas, generates personalized learning roadmaps, and provides AI-powered interview preparation.

Unlike traditional learning platforms, PlacementPilot AI focuses on helping students become placement-ready through guided career development, practical recommendations, and continuous progress tracking.

This project is being developed as part of the Microsoft Agents League Hackathon 2026 under the Creative Apps track.
## Features

- AI Placement Mentor
- Skill Gap Analysis
- Personalized Learning Roadmaps
- Mock Interview Preparation
- Career Guidance
- Progress Tracking

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- GitHub Copilot
